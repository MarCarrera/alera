
# Changelog


## 1.0.1

### Documentation
- Added screenshots showcasing all six alert types.
- Added video demonstrations of animated dialogs and transitions.
- Improved README documentation with a visual preview gallery.
- Added screenshots metadata for pub.dev.

### Example
- Redesigned the example application as Alera Showcase.
- Added a visual style selector.
- Added advanced demonstrations for actions, transitions, and loading.
- Improved navigation and organization of the available examples.

### Maintenance
- Excluded demonstration videos from the published package.
- No breaking API changes.


## 1.0.0

- Initial stable release of Alera.
- Added six alert types: success, warning, error, fail, info, and loading.
- Added three visual styles: classic, floatingTop, and cornerBadge.
- Added configurable entrance and exit transitions.
- Added animated semantic icons and a custom loading spinner.
- Added animated loading messages.
- Added support for up to two actions on standard alerts and one optional action on loading alerts.
- Added programmatic loading dismissal through AleraController.
- Added customizable colors and themes.
- Improved responsive layouts and accessibility support.
